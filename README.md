# ariona
Ariona is a minimalist x86_64 operating system written in pure NASM. It boots straight from UEFI, finds your programs on a USB stick, and runs them — no kernel, no libc, no layers in between. Drop an .obj on the drive and it runs on boot. Want a menu? Drop a .bin and pick it. Ariona is what happens when you strip an OS down to the only thing that matters: running your code.
